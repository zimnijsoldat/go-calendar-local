# GO Calendar in Melbourne time

A copy of the [GO Calendar](https://github.com/othyn/go-calendar) feed (events from
[Leek Duck](https://leekduck.com/events/)) with every event time pinned to
`Australia/Melbourne`. Google Calendar URL subscriptions show the original
floating times as UTC; this copy fixes that.

A GitHub Action refreshes `gocal-melbourne.ics` twice a day.

Subscribe in Google Calendar (Other calendars → + → From URL):

```
https://raw.githubusercontent.com/zimnijsoldat/go-calendar-local/main/gocal-melbourne.ics
```
